# 테트리스

라이브러리 없이 **HTML · CSS · JavaScript 만으로** 만든 테트리스입니다.
`index.html` 을 브라우저에서 열면 바로 시작합니다. 설치도, 서버도, 빌드도 필요 없습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조 (보드 canvas + 점수 패널 + 오버레이) |
| `style.css` | 스타일 (day01 과 같은 다크 토큰 체계) |
| `script.js` | 게임 로직 전부 — 조각 정의, 충돌 판정, 게임 루프, 렌더링 |
| `PLAN.md` | 만들기 전에 정한 설계 기준선 |
| `README.md` | 이 문서 |
| `WORKFLOW.md` | 제작 과정 기록 |
| `test/logic.test.js` | 로직 테스트 (개발용, 실행에는 불필요) |

의존성은 Google Fonts(IBM Plex) 하나뿐이고, 폰트를 못 불러와도 시스템 서체로 정상 동작합니다.

## 실행

`index.html` 을 더블클릭해 `file://` 로 열어도 그대로 동작합니다.
외부 파일을 `fetch` 하지 않으므로 CORS 에 걸릴 곳이 없습니다.

로컬 서버로 열고 싶다면:

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## 조작

| 키 | 동작 |
|---|---|
| `←` `→` | 좌우 이동 |
| `↑` | 회전 (시계 방향) |
| `↓` | 한 칸 빨리 내리기 |
| `Space` | 바닥까지 즉시 내리기 |
| `P` | 일시정지 / 해제 |
| `R` | 다시 시작 |

방향키와 스페이스는 페이지 스크롤을 막아 두었습니다.
탭을 벗어나면 자동으로 일시정지됩니다.

## 규칙

### 점수

| 상황 | 점수 |
|---|---|
| 1줄 삭제 | 100 |
| 2줄 동시 | 300 |
| 3줄 동시 | 500 |
| 4줄 동시 | 800 |
| `↓` 로 한 칸 | +1 |
| `Space` 로 한 칸 | +2 |

여러 줄을 한 번에 지울수록 크게 유리합니다 (1줄씩 4번 = 400점, 4줄 한 번 = 800점).

### 레벨과 속도

10줄을 지울 때마다 레벨이 1 오르고, 낙하 간격이 70ms 씩 짧아집니다.
레벨 1은 800ms, 하한은 100ms 입니다.

### 조각

7종(I O T S Z J L)을 **한 벌씩 섞어 순서대로** 내보냅니다(7-bag).
매번 무작위로 뽑으면 같은 조각이 연달아 몰리거나 I 조각이 한참 안 나오는데,
7-bag 은 7개마다 모든 조각이 정확히 한 번씩 나오는 것을 보장합니다.

## 테스트

로직 검증용 테스트가 들어 있습니다. **게임 실행에는 필요 없습니다.**

```bash
node test/logic.test.js
```

90개 항목(조각 정의·충돌 판정·줄 삭제·점수·레벨업·하드드롭·회전 킥·게임오버·7-bag)을 확인합니다.
테스트는 `script.js` 를 텍스트로 읽어 최소한의 DOM 스텁과 함께 실행하므로,
`script.js` 에는 Node 전용 코드가 한 줄도 들어 있지 않습니다.

## 구조

```
board (ROWS×COLS 배열)  ──→  draw()      배열만 읽어 캔버스에 그림
                             drawNext()

move() / rotate() / stepDown() / hardDrop()
        └──→ isValid()   ← 벽·바닥·쌓인 블록 판정이 여기 한 곳뿐

loop(t)  requestAnimationFrame + 경과시간 누적
         누적이 dropInterval 을 넘으면 한 칸 낙하
```

두 가지가 이 코드의 뼈대입니다.

**보드 상태와 렌더링을 분리** — 보드는 색 문자열이 든 2차원 배열이고, 렌더는 그 배열만 읽습니다.
캔버스에서 픽셀 색을 읽어 판정하는 식으로 섞지 않았습니다.

**충돌 판정은 `isValid()` 하나** — 이동·회전·자동낙하·하드드롭이 전부 이 함수를 거칩니다.
각자 경계 검사를 복사해 가지면 "왼쪽 벽은 막히는데 회전으로는 뚫린다" 같은 버그가 생깁니다.

낙하 타이밍은 `setInterval` 이 아니라 `requestAnimationFrame` + 경과시간 누적으로 돕니다.
탭이 백그라운드로 가면 `setInterval` 은 타이밍이 어긋나기 때문입니다.
돌아왔을 때 조각이 순간이동하지 않도록 프레임 간격을 100ms 로 잘라 냅니다.

## 의도적으로 넣지 않은 것

MVP 범위를 지키기 위해 뺐습니다.

- **홀드(조각 보관)** — 조작 키와 상태가 하나 더 늘어납니다.
- **고스트(착지 위치 미리보기)** — 없어도 게임이 성립합니다.
- **SRS 월킥 전체** — 벽 옆에서 회전이 막히는 답답함만 없애려고 좌우 ±1, ±2 만 밀어 봅니다.
- **최고 점수 저장 · 사운드 · 모바일 터치 조작**
